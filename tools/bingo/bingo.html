Help and data format

Playing

  • Click or keyboard-activate a square to validate it. Click it again to unvalidate it.
  • Counter squares advance by one on each click and show their progress. Clicking a completed counter resets it.
  • Use the striped highlight control on a square to mark it without changing its progress. Highlighting and validation can be combined.
  • Use the information control, or hover a square on desktop, to see its description.
  • The timer starts when a grid is generated. Completed rows, columns, and diagonals are listed with their completion times. Completing a line or the whole board does not stop the game.

Loading a dataset

Choose a JSON file, enter an optional whole-number seed, and select Generate. The same dataset and seed always produce the same grid. If the seed is blank, a random seed is generated and shown so you can reuse it.

Loading another dataset does not change the active board; it is used the next time you generate. Clear game removes the board and saved progress but keeps the loaded dataset.

JSON format

A dataset has a grid object and a squares array. Grid size is a positive integer; freeSpace is optional and defaults to false. A free space occupies and validates the center of an odd-sized grid. tagCounts gives exact counts, not weights, and must add up to the number of grid cells that need squares.

Each square needs a unique string id, a name, a type (instant or counter), and a string tag. description is optional. Counter squares also need a positive integer amount. Squares with tags absent from tagCounts are accepted but not used to generate a grid.

Each configured tag must have enough unique squares. Invalid JSON, configuration, or insufficient squares will be reported instead of generating an incomplete board.
